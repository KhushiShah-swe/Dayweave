# Roadmap

The current release is a local portfolio prototype. These are planned improvements, not completed capabilities.

| Priority | Work | Completion signal |
| --- | --- | --- |
| Next | Browser visual and keyboard review | Desktop and mobile layouts checked; focus returns after dialogs; screenshots recorded from the real app |
| Next | Configured provider integration check | GitHub sign-in and Spotify/YouTube consent, sync, expiry, and disconnect verified with dedicated test accounts |
| Next | Secure deployment design | HTTPS, token encryption, session strategy, CORS, backups, host allowlist, and a persistent database defined |
| Later | Pagination and backfill | API and UI paginate; provider history limits are explicit |
| Later | Durable sync jobs | Retries, rate-limit backoff, per-connection status, and distributed coordination |
| Later | Export/import portability | A versioned import format with validation, previews, and duplicate handling |
