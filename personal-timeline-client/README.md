# Dayweave client

React + TypeScript client for Dayweave. See the [project README](../README.md) for the product walkthrough, screenshots, architecture, setup, and contribution history.

```sh
npm ci
npm run dev
```

Open http://localhost:3000 and choose **Explore the demo**. The demo runs entirely in your browser with fictional data. To use real accounts, run the .NET API and configure `VITE_API_URL` using `.env.example`.

```sh
npm test
npm run build
npm run preview
```
